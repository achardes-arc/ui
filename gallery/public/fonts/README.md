# Gallery fonts

Local WOFF2 files reused from the existing Calque app to render the Arcadran reference faithfully. These demo assets are excluded from the npm package.

- Archivo — Omnibus-Type: https://github.com/google/fonts/tree/main/ofl/archivo
- Chakra Petch — Cadson Demak: https://github.com/google/fonts/tree/main/ofl/chakrapetch
- JetBrains Mono — JetBrains: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Each family uses the SIL Open Font License 1.1. Corresponding license texts are stored beside these files.
